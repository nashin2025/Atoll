- **Security Issues** — See [SECURITY.md](SECURITY.md) for private reporting

### Response Times

| Issue Type | Expected Response |
|------------|-------------------|
| Security vulnerability | 24 hours |
| Bug report | 3 business days |
| Feature request | 1 week |
| General question | 3 business days |

## Filing Issues

When filing an issue, please:

1. Search existing issues to avoid duplicates
2. Use the appropriate issue template (bug report or feature request)
3. Provide clear steps to reproduce (for bugs)
4. Include relevant version information
5. Be respectful and constructive

## Contributing

We welcome contributions! See [CONTRIBUTING.md](CONTRIBUTING.md) for details on

## Security

For security vulnerabilities, please refer to [SECURITY.md](SECURITY.md) and
use the private reporting channel described there. Do not disclose security
issues publicly.
